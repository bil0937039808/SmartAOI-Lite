# SmartAOI-Lite: 智慧產線瑕疵檢測與 MES 數據自動化採集系統
# OpenCV影像辨識與MySQL資料庫整合

根據製造業數位轉型（OT to IT）設計的輕量化驗證專案（PoC）。
本專案模擬工業相機於生產線的取像流程，透過 **Computer Vision (OpenCV)** 進行即時表面瑕疵檢測與產品條碼識別，並結合 **RPA 腳本與 RESTful API** 邏輯，將現場生產數據毫秒級同步至後端資料庫，實現產線數據自動化採集與生產履歷追溯。

---

## 🎯 專案核心痛點與解決方案

*   **傳統產線盲檢失誤：** 依靠人工檢驗容易因疲勞導致漏檢。本專案利用**電腦視覺算法**實作第一道防線的自動化幾何/色彩篩選。
*   **資訊孤島（IT/OT 斷層）：** 產線機台數據無法即時關聯至 ERP/MES 系統。本專案利用 **RPA 自動化腳本外掛 API** 串接，打通底層 CIM 與上層資料庫的資料流。
*   **系統高容錯需求：** 考量工廠環境的網路波動，採用標準化 API 封裝，並預留模組化設計以便未來擴充非同步隊列（如 Redis Queue）。
